## เครื่องมือสำหรับคณาจารย์ในพอร์ทัลนี้

1. **ตารางสอน & ภาระงานสอนรายอาจารย์ (19 ท่าน)** พร้อมบันทึกผู้ประสานงาน (`[รอยืนยัน]`) และปุ่มเปิดรายชื่อกลุ่มย่อยทันที
2. **ใบรายชื่อและรูปถ่ายนักศึกษา (169 คน)** แยกตาม `Discussion 1–6` และ `9 พื้นที่ภาคสนาม` พร้อมระบบจัดพิมพ์ลง **กระดาษ A4 หน้าเดียวอัตโนมัติ** และลิงก์เชื่อม Google Apps Script ต้นฉบับ
3. **แผงตรวจสอบตารางสอน & ซิงค์ชีต Apps Script (`schedule-racm303-v1`)** สรุป 7 ประเด็นรอยืนยัน รายการที่ซ่อมแซมแล้ว และไฟล์ `downloads/schedule_racm303_v2_revised.csv` สำหรับนำไปวางอัปเดตฐานข้อมูล Google Sheet
4. **คู่มือผู้สอน (`HS1` & `HS2` Teacher Guides)** บันทึกตรวจทาน `HS3–HS6` แผนการศึกษาหลักสูตร และสารบัญลิงก์ Google Drive / Google Docs / คลังข้อสอบ `RACM303_Exam_2569`
5. **เอกสารอ้างอิงชุดเดียวกับผู้เรียน** (คู่มือรายวิชา 17 บท เอกสารคำสอน `HS1–HS6` และคลังคำศัพท์/โจทย์ 82 ข้อ)
