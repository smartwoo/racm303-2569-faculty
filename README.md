## ฟีเจอร์หลักสำหรับคณาจารย์และผู้ประสานงาน

- **ปฏิทินสอนสไตล์ Google Calendar & Apple iCal (`เดือน` · `สัปดาห์` · `กำหนดการ`)** — เลือก **เฉพาะอาจารย์ผู้สอน (19 ท่าน)**, **เฉพาะกลุ่มภาคสนาม (9 พื้นที่ ตามวัน–เวลาเดินทางจริง)**, หรือ **เฉพาะตัวนักศึกษา** แล้วเลือกได้ทั้ง **นำเข้าไฟล์ `.ics` / `.csv` ครั้งเดียว** และ **สมัครรับลิงก์ Subscribe URL (`.ics` / `webcal://` ในโฟลเดอร์ `calendars/`)** เพื่อให้ Google Calendar / Apple Calendar อัปเดตอัตโนมัติ พร้อมฝังลิงก์ Zoom ในตัว
- **แยก 3 หมวดงานชัดเจนไม่ปนกัน:**
  1. **ใบรายชื่อรูปถ่ายกลุ่ม Discussion (`#discussion`)** — แยกเฉพาะกลุ่มอภิปราย 1–6 พร้อมตารางหมุนเวียนอาจารย์และห้องเรียน `HS1–HS6` และพิมพ์ลง A4 หน้าเดียว
  2. **9 พื้นที่ภาคสนาม (`#fieldwork`)** — แยกรายละเอียดโรงพยาบาลชุมชน อาจารย์ที่ปรึกษา เจ้าหน้าที่ประสานงาน กำหนดการเดินทาง และใบรายชื่อรูปถ่ายรายพื้นที่
  3. **การส่งงาน & เชื่อมต่อระบบหลังบ้าน RAMED E-learning (`#submissions`)** — เชื่อมต่อตรงสู่ `https://elearning.ra.mahidol.ac.th/ramed/login/index.php` รองรับเปิดหน้าต่างคู่ขนาน ปักหมุดลิงก์ห้องตรวจงาน Assignment และตรวจรูปแบบไฟล์ PDF (`≤ 5 หน้า A4`)
